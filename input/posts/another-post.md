## Code Highlighting

Stellar uses [Prism.js](https://prismjs.com/) for code syntax highlighting.

```csharp
public class ExampleClass
{
    public string Message { get; set; } = "Hello, World!";

    public void PrintMessage()
    {
        Console.WriteLine(Message);
    }
}
```
