Welcome to the **Stellar** theme for [Statiq](https://statiq.dev)!

This theme is a port of the [HTML5 UP Stellar](https://html5up.net/stellar) design, adapted for Statiq Web using the [CleanBlog](https://github.com/statiqdev/CleanBlog) template as a structural guide.

## Features

- Clean, responsive design based on HTML5 UP Stellar
- Archive page listing posts by year
- Tag-based filtering
- RSS and Atom feeds
- Search support

## Getting Started

1. Update `settings.yml` with your site title, description, and other preferences.
2. Add your blog posts to the `posts/` directory in Markdown or HTML format.
3. Customize the theme by editing the partials in the `input/` directory.
4. Build and run your site with `dotnet run`.

## Customization

The Stellar theme is fully customizable. You can override any partial by creating a file with the same name in your project's `input/` directory. The theme will use your version instead of the default.

For more information on how to use Statiq Web, see the [Statiq Web documentation](https://statiq.dev/web/).
